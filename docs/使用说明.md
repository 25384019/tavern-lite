# 使用说明（酒馆 / Tavern Lite）

这一份是给用的人看的：每个功能在哪儿、怎么走一遍闭环。设计细节看
`ARCHITECTURE.md`、`AI-CARD-STUDIO-SPEC.md`，交付状态看 `../HANDOFF.md`。

---

## 0. 先配好模型

**我的 › 模型与连接**

- 用 DeepSeek 官方：填 API Key，选模型
- 用别的 OpenAI 兼容服务：新建一个配置（Base URL / 模型名 / Key），设成当前

AI 功能全部走这里；没配 Key 时按钮会提示，不会静默失败。

---

## 1. AI 制卡（从一句灵感出一张卡）

**酒馆 › 书架 › 右上角 ✨（AI 制卡）**

1. 写一句灵感（也可以只在「世界观」「关系」里写一点）
2. 选**快速**或**高级**
3. 生成 → 先看预览（名字、外貌、开场白、世界书条目数）→ **采用**才存进书架

生成的卡是标准 V3 卡，可以导出、可以在别的 ST 里打开。

---

## 2. 专业创作（九个模块，逐字段写）

**书架 › 右上角 ＋** 或 **角色页 › 设置 › 专业创作**

九个模块：人物档案 / 深度人格 / 玩家关系 / 世界与背景 / 场景与初遇 / 对话与文风 /
经历与秘密 / 灵魂 / 工程。

- **每格右上角 ✨**：补全 / 扩写 / 精简 / 重写（会问你一句要求）/ 检查
- **模块页右上角 ✨**：整模块生成（只填空着、没锁的格子）
- **🔒 锁定**：锁住的格子 AI 永远不碰（解析层就丢掉了，不是靠界面自觉）
- **↺ 撤销**：每次改动都留一步
- **候选面板**：旧的和新的并排，**采用**才写，**丢弃**什么都没发生

### 2.1 状态（跟着卡走）

模块列表里有一行 **状态**：

- 选一个**状态模板** → 存出来的卡带着这套状态，舞台的「状态」标签立刻能用
- 或者 **AI 按角色设计**：先列候选（名称/键/初始值），采用才写
- 「不要状态」清掉

### 2.2 世界书条目

在「世界与背景」「玩家关系」「经历与秘密」「规则」这几个模块里，
整模块菜单里有 **生成世界书条目**：拆成 3~6 条带关键词的条目，采用后进草稿，
存卡时写进卡片的 `character_book`。

### 2.3 存回已有的卡

**角色页 › 设置 › 专业草稿**：

- 卡里有草稿 → 读回来接着改
- 卡里没有 → 用它现有的内容（名字/描述/性格/场景/开场白/标签）起一份，不让你重打
- 保存 = 改正文 + 补卡里缺的条目 + 存草稿，**不会多出一张卡**

---

## 3. 内置内容（随包带来的 15 本世界书 + 3 张角色卡）

**资源库 › 内置内容**

- 列出随包的全部素材（15 本世界书、3 张角色卡），名字就是原文件名
- 点 **全部装进来**：一次装完，按名字去重——装过的不会再装，删了可以再装回来
- 装完直接在世界书/书架里能看到，不用退出重进

不联网，素材就在 APK 里。

**资源库 › 状态模板**

- 新建模板 → 逐项加状态项：名称、内部键、类型（数字/文本/布尔/枚举/列表）、初始值；
  数字有最小/最大，枚举有选项，可以「藏起具体数值」
- 保存前会自检：键为空、重复、带中文、范围反了、枚举没选项 → 都不让存并指出是哪一项
- **应用到角色**：选一张卡写进它的状态；卡里已有状态会先问再覆盖
- 删除模板不会影响已经用到卡上的状态

---

## 4. 世界书

**资源库 › 世界书**

### 4.1 从零写一本

右上角 ＋：

- **导入**：ST 的 JSON 直接能读
- **新建空白**：起个名字
- **世界书工坊**（AI）：
  1. 一句创意 + 规模（小/中/大）
  2. **生成蓝图**（名字、概述、规则、势力、地点、矛盾）
  3. **规划条目**（逐条勾选要写哪些）
  4. **写正文**（每批 ≤8 条，每条可以改、可以删）
  5. **一致性检查**（找出和蓝图冲突、条目互相冲突、写了等于没写的地方）
  6. **存成世界书** → 变成一本普通的世界书，之后照常在条目页里改

### 4.2 条目管理

打开一本书：

- **顶部搜索**：按名字、关键词、正文过滤
- **右上角「选择」**（超过 1 条才出现）：全选 / 取消全选 / 批量启用 / 批量停用 / 批量删除
- 删除要确认；删除是从后往前删的，不会删错

### 4.3 单条条目

点一条进编辑页：

- 内容格右上角 ✨：**写长 / 精简 / 按说明重写 / 给几个关键词**
- 专业触发：递归、分组、冷却、正则、扫描深度、关键词当正则
  - 注意：**扫描深度填 0 = 这条永不按关键词匹配**（不填才是用全局）
  - 「只在递归里出现 + 递归里跳过」这对组合会被挡住，因为它永远不生效

### 4.4 调试：哪些条目会触发

**书名右上角 ▶（试试）**：输入一句话，看哪些条目命中、命中的是哪个关键词、有没有超出预算。

### 4.5 版本快照（改坏了能退回来）

**书名右上角「版本」**：

- **存一份快照**：把这本书现在的样子存下来（每本最多留 20 份，超了自动丢最旧的）
- 列表按时间倒序，带体积；点一版可以 **回到这一版**（会先问一句）
- 某一版不想要了可以单独删

快照存在本地，不进卡、不进导出的 JSON。

## 5. 预设

**资源库 › 预设**

- 右上角 ＋ **新建空白**：起名，建完进编辑页
- 条目菜单：编辑 / **复制一份** / 设为默认 / 导出 / 删除 / 报告
- 编辑页：上下文、回复长度、温度、预填充、提示词列表（开关、顺序、位置）
- **提示词内容那行右边 ✨**：从头写 / 写长 / 精简，可以补一句「想要什么」，
  先看候选，采用才保存

设成默认或绑到某条对话上之后，**真的会生效**（引擎按选中的预设走）。

## 6. 已知限制（诚实清单）

1. **AI 制卡用真 Key 验证过多次**（DeepSeek 官方接口，2026-11-16）：灵感 → 真模型 → 预览
   （生成完会**自动滚到预览**）→ 存进书架 → 重启还在。实测两次成功，用量 938 / 1254 tokens。
   **其余 AI 功能（专业创作逐字段、世界书四阶段、状态方案、预设提示词、三场景试演）只用模拟回复
   验证过**——它们共用同一套传输与「先给候选」流程，但提示词形状不同，不能拿制卡的成功代替。
   世界书四阶段在主人实测中也跑通过（见上面的记录），但没做逐条断言。
2. 模型被 token 上限截断时，卡片 JSON 尾巴会缺一截；现在会自动修补（退到最后一个完整字段再收尾），
   修不回来会显示「模型原文」让你自己看。
3. 世界书的**图谱 / 时间线**、预设的 **A/B 对比**、导演模式等扩展项**没做**。
4. 状态只有「定义 + 初始值」，**每回合自动变化的规则（rules）没接**（引擎支持，界面没做）。
5. 卡片的 `character_book` 只能往里面**补**条目，不能删（引擎没给删除 API）。
